# Employee Onboarding Using Microsoft Entra and ServiceNow

## Project Overview

In this lab, I practiced how an IT support technician handles an employee onboarding request. The goal was to create accounts for two new employees in Microsoft Entra, assign them to the correct security groups, and make sure they could successfully sign in.

I also used ServiceNow to document the request, track the work I completed, and resolve the ticket.

## Scenario

The HR department submitted a request to onboard two new employees:

- **Jessica Brown** – HR Assistant, HR Department
- **Michael Davis** – IT Department

Both employees needed Microsoft Entra accounts and access to their assigned department groups.

## Tools Used

- Microsoft Entra 
- ServiceNow
- Microsoft 365 sign-in page
