# Microsoft-Entra-ServiceNow-Labs
Microsoft Entra and ServiceNow labs demonstrating employee onboarding, password resets, account offboarding, access management, and IT support documentation.

## Projects

### 1. [Employee Onboarding](01-Employee-Onboarding/README.md)
Created employee accounts in Microsoft Entra, assigned security group memberships, verified account access, and documented the onboarding process in ServiceNow.

### 2. [Password Reset](02-Password-Reset/README.md)
Handled an employee password reset request, configured a required password change, verified successful sign-in, and resolved the ServiceNow ticket.

### 3. [Employee Offboarding](03-Employee-Offboarding/README.md)
Disabled an employee account, removed security group access, revoked sign-in sessions, tested account access, and documented the offboarding process in ServiceNow.
